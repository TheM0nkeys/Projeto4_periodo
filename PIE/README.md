### 🧹 Organização e Limpeza do Projeto

Para mantermos o projeto escalável e de fácil manutenção, seguimos as diretrizes abaixo:

- **Roteamento:** Utilizamos roteamento *Client-Side* (SPA) para gerenciar a navegação sem a necessidade de criar múltiplos arquivos HTML desnecessários.
- **Gestão de Assets:** Evitem a criação de arquivos ou imagens redundantes (como prints obsoletos). 
- **Limpeza:** Periodicamente, removam arquivos inativos (`READMEImages/`, arquivos de teste obsoletos, etc.) para evitar poluição no repositório, como:
    - ~~`READMEImages/PecasOriginal.png`~~
    - ~~`READMEImages/PecasGreg.png`~~

*Mantenham o diretório limpo para facilitar a leitura do código por todos.*
